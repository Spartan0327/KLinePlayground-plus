# KLinePlayground-plus · A 股 K 线复盘训练器

一个跑在本地桌面上的 A 股复盘训练工具：用真实历史行情逐根 K 线回放，按 A 股规则模拟买卖（T+1、佣金、印花税、四档复权），训练自己的盘感和纪律；一局结束后可以让大模型做结构化复盘，并把反复出现的问题沉淀成可追踪的档案。

- 形态：PyWebView 桌面窗口（Python 后端 + 本地 Web 前端），不依赖浏览器，不上传数据
- 版本：界面版本 v3.2.0，功能改造阶段 V2.1 / V2.2 / V2.3（详见「与上游版本的差异」）
- 来源：基于 [fat7/KLinePlayground](https://github.com/fat7/KLinePlayground)（MIT）的本地改造版，保留上游署名与许可证

> 仅供学习和复盘训练使用，不构成投资建议。行情来自公开数据源，可能有缺失或延迟。

## 功能

### 训练

| 功能 | 说明 |
| --- | --- |
| 指定模式 | 手工填股票代码 + 起始日期，从该日开始逐根回放 |
| 盲盒模式 | 随机抽股票和起始区间，可按板块筛选（全部 / 主板 / 创业板 / 中小板），避免带着后见之明选票 |
| 数据源 | AKShare（默认，免费公网）、xtdata（需本机 QMT 环境）、mootdx（通达信协议）、本地离线数据 |
| 回放控制 | 手动「下一根」，或按速度自动播放；可回退 |
| K 线周期 | 新建训练可选日 K / 周 K；训练中也能在日 K、周 K 之间来回切换视图（同一段行情按周线聚合后回放） |
| 交易规则 | T+1（当日买入次日才能卖）、佣金（默认万三、最低 5 元）、印花税（默认千一，仅卖出）、加仓减仓、清仓 |
| 快捷键 | B 买入、S 卖出、空格播放/暂停、数字键设数量，界面内置快捷键表 |
| 账户 | 总资产、可用资金、持仓市值、浮动盈亏、持仓明细实时更新 |
| AI 实时陪练 | 训练中点「AI 陪练」开面板提问。它只读当前 Bar 及之前的行情、指标、持仓与规则，不预测后续走势；回答按「结论 / 依据 / 风险与反方 / 观察点」给条件式判断，把决定权留给你 |

### 图表

- K 线 + 成交量，基于 Lightweight Charts，支持缩放、十字线联动
- 技术指标：MACD、KDJ、RSI、BOLL，可切主图 / 副图，参数可改
- 均线：最多 6 条自定义周期（如 MA5 / MA10 / MA20 / MA60 / MA120 / MA250），自动配色
- 复权：不复权 / 前复权 / 后复权 / 动态前复权，训练中可切换
- 筹码分布与筹码获利比例
- 成本线辅助：以持仓均价为基准画止损线、止盈线，价格轴自动扩展容纳
- 禁买期提示：清仓后 N 根 K 线标「禁买」，只提示不拦截下单

### 复盘

- 训练总结：股票、训练区间、初始资金、最终资产、交易次数、胜率、最大回撤、总收益率
- 交易明细：Bar、日期、方向、价格、数量、金额、税费、净金额
- 全程走势与我的收益率：上图 K 线 + 买卖点，下图净值指数（100 = 初始资金），支持线性 / 对数切换
- AI 复盘报告（需自备模型 Key）：总体印象、做得好的地方、核心问题、交易纪律、改进建议、历史问题对照、双维度评分
  - 双维度评分互相独立：A 交易执行质量（纪律 30 / 建仓节奏 20 / 卖出与持仓 20 / 仓位与风险 20 / 执行一致性 10）；B 收益表现（净收益 25 / 回撤 25 / 盈亏结构 20 / 稳定性与集中度 20 / 资金效率 10）
  - 数据不足的维度标 N/A 并按有效权重重算，不允许编造分数
- 重点交易深度点评（V2.3）：每轮最多 3 笔，宁可少选；金色 ★ 标记 + 淡金色完整周期高亮，点开是阶段编号、建仓到清仓时间、相关成交、操作过程、AI 评价、优点、问题、经验，以及可跳转到曲线的证据成交
- 普通买卖点只呈现事实：红 ▲ 买入 / 绿 ▼ 卖出，点开是日期时间、fill_id、周期编号、方向、价格、数量、Bar ID、action_type、买卖前后持仓，不掺 AI 评价
- 成交上限与披露：单轮最多 150 笔送模型，超出按最早 N 笔截断并在报告里写覆盖率；提示词过长时自动减半重试，最低 15 笔
- 卖出评价口径：只按决策当时可见的信息（成本、浮盈、仓位、已完成 K 线、既定规则）判断，卖出之后的走势算事后信息，不用来倒推当时卖得对不对，也不对「提前止盈」和「持有回撤」用两套相反标准
- 复盘数据包导出：报告页点「导出复盘数据包（MD）」，把该轮 K 线走势、逐 Bar 行情与资金、全量成交（含持仓变化与周期）、成交窗口 K 线、重点交易、历史问题档案、AI 复盘原文一起导出成一份 Markdown，方便拿去外部讨论买卖与卖出规则

### 历史问题档案

- 模型侧状态：NEW / RECURRED / IMPROVING / NOT_OBSERVED / INSUFFICIENT_DATA
- 你的侧状态：待改进 / 持续观察 / 已改善 / 已解决 / 暂不处理
- 每轮复盘自动追加证据与观察记录，原问题 ID 不变
- 你自己改过的标题、描述、分类、建议规则、备注、状态不会被下一轮 AI 覆盖
- 版本审计：每次变更留记录
- 支持导出、备份、还原

### 设置（主界面「设置」按钮）

- 默认初始资金、佣金费率、最低佣金、印花税率、界面主题（浅色 / 深色）
- AI 接口配置：base_url、模型名、API Key（留空则沿用已保存的 Key）、测试连接、清除配置
- AI 复盘提示词：可留空用内置模板，可载入默认模板查看，也可清空退回默认；支持 `{stock_code}` `{start_date}` `{end_date}` `{total_return}` `{max_drawdown}` `{total_trades}` `{trade_win_rate}` `{final_capital}` 占位符
- 清仓后禁买期天数、止损 / 止盈百分比、均线周期、MACD / KDJ / RSI / BOLL 参数
- 「开启 AI 介入」：把本地 API 地址与端点写给 `ai_assistant_tester.py` 读取，供其自动交易

### 多用户

创建、切换、删除用户；每个用户的训练记录、设置、历史问题档案、提示词各自独立。

## 快速开始

环境：Windows 10/11，Python 3.10+（实测 3.12）。桌面窗口依赖系统 WebView2 运行时，Win10/11 一般已自带；缺失时先装 `installer_source/MicrosoftEdgeWebview2Setup.exe`。

```bash
git clone https://github.com/Spartan0327/KLinePlayground-plus.git
cd KLinePlayground-plus
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

启动：

```bash
start.bat                                    # 无控制台窗口，日常用这个
.venv\Scripts\python webview_app\main_pywebview.py   # 想看日志就用这个
start-debug.bat                              # 同上，带控制台
```

说明：

- 后端 Flask 服务由桌面程序自己拉起，端口**随机分配**（避开浏览器禁用端口），不需要手工访问网址，也不要指望固定端口
- 前端改动需要关掉窗口重新启动才会生效
- `requirements.txt` 里的 `lightweight-charts` 目前用不到（图表库已内置在前端目录），装着也不影响

## 第一次打开看到什么

只有一个「选择用户」页面：没有历史用户时列出空状态，输入用户名点创建即可进入主界面。这时账户、训练记录、AI 配置、历史问题档案都是空的——这是一个干净安装的正常样子。

进入主界面后先别急着点「新建训练」：新装的程序**没有任何行情数据**，直接开始训练会得到明确报错：

- 选本地离线数据：`指定股票在离线数据中不存在`
- 盲盒模式选离线数据：`离线数据中没有符合板块与日期范围的股票`

先按下一节补数。

## 数据准备

程序的数据都在项目根的 `data/` 下（该目录不进仓库，首次运行自动创建）：

| 路径 | 用途 |
| --- | --- |
| `data/a_market_offline/` | 本地离线 K 线，选「本地离线数据」时读这里。文件名形如 `000001.SZ.csv` / `600026.SH.csv` / `830799.BJ.csv`；编码支持 UTF-8 / GBK；必需列 `date open high low close volume`（也认中文表头「交易日 / 开盘价 / 最高价 / 最低价 / 收盘价 / 成交量（手）」），可选 `amount turnover_rate factor` |
| `data/kline_raw/`、`data/factor/`、`data/ex_dividend/` | 在线数据下载后的本地缓存与复权因子、除权数据 |
| `data/stock_list.csv`、`data/stock_names.json` | 股票列表与名称。缺失时程序启动会在后台自动下载（AKShare），不阻塞界面；下载完成前补数页会提示「股票列表还在后台下载」 |
| `data/.ai_tester_config.enc` | AI 配置（含 Key），本地加密文件，已被 `.gitignore` 排除 |

补数步骤：

1. 主界面点「数据更新器」
2. 选补数范围：单只股票 / 全沪市 / 全深市 / 全市场
3. 选在线数据源：AKShare（默认；xtdata、mootdx 需本机具备相应环境才显示）
4. 填日期区间（可留空表示尽量补齐），需要推倒重来就勾「重新全量覆盖，不走增量逻辑」
5. 点「开始补数」。程序会先看本地已有区间，只补缺口，过程中有进度条，结束给出新增条数、实际抓取区间、在线源未返回的区间

批量补全市场耗时较长，受在线源限速影响，建议先补几只自己常做的票。补完之后把训练数据源切到「本地离线数据」，之后训练不再依赖网络。

## 配置 AI 复盘

全部在应用里完成，不用改文件：

1. 「设置」→「AI 接口配置」
2. 填 base_url（如 `https://api.deepseek.com/v1`）、模型名（如 `deepseek-chat`）、API Key
3. 点「测试连接」，看到成功提示再点保存
4. 想换 Key 直接覆盖；想停用点「清除配置」

细节：

- Key 只写本地加密文件 `data/.ai_tester_config.enc`（XOR + base64，与命令行工具共用），界面只显示掩码，不会回显完整 Key
- 保存后下一轮复盘立即生效，不需要重启
- 提示词留空就用内置的 V2.3 模板（含重点交易选择标准与历史问题更新协议）；想按自己的纪律加检查项，直接在「AI 复盘提示词」里写
- 也可以走命令行：`配置AI.bat` 或 `python set_ai_config.py`
- 所有 AI 请求由你主动点「AI 复盘」触发，模型地址和 Key 由你自己提供
- 训练中的「AI 陪练」共用这份配置：每问一次带当前 Bar 快照与最近 40 根 K 线（追问只带快照），数据边界写死在提示词里——模型看不到当前 Bar 之后的任何行情

## 复盘报告怎么读

| 标记 | 含义 |
| --- | --- |
| 红色 ▲ + 「买入」 | 真实买入成交，点开只看事实 |
| 绿色 ▼ + 「卖出」 | 真实卖出成交，点开只看事实 |
| 金色 ★ + 「重点」 | 值得深挖的完整交易周期，点开是深度点评；同周期的成交区间有淡金色高亮 |
| 「禁买」 | 清仓后冷却期提示，不是 AI 结论 |

- V2.2 及更早的旧报告里保存的逐笔 AI 点评（`fill_reviews`）仍在数据库里，但新版界面默认不再展示，接口标记为 legacy；旧报告打开时只显示交易事实与重点交易
- 报告数据写在每个用户自己的 `users/<用户名>/` 目录与 `training_history.db` 中，删除用户会一并删除

## 已知限制

- 新装程序没有行情数据，必须先补数才能训练
- 周 K 目前是「日线聚合成周线」的回放口径：指标、买卖与统计都按聚合后的周线计算，不是交易所原始周线文件
- 后端 `app_enhanced.py` 是单文件大模块（路由、训练编排、AI 调用、结构校验混在一起），改起来不够清爽
- 仓库里没有自动化测试目录，验收靠临时脚本与真实窗口实测
- AI 功能需要自备模型 Key，费用由你承担；不同模型对结构化输出的稳定性差异较大
- 桌面窗口的端口是随机分配的，不要按固定端口写外部工具
- 只在 Windows 上实测过
- 根目录还留着一些历史资产：`hma_demo.py`（独立的 HMA 指标演示）、两个哈希命名的 jpg（当前无引用）、若干 `.spec` 打包配置，均不影响主程序

## 常见问题

**启动后窗口一片空白**
多为 WebView2 运行时缺失或端口异常。先 `start-debug.bat` 看控制台报错；确认装了 WebView2；再关窗重开一次。

**`pip install -r requirements.txt` 很慢或卡在 akshare**
AKShare 依赖较重，换国内镜像重试：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`。

**点新建训练提示「指定股票在离线数据中不存在」**
数据源选了「本地离线数据」但本地没有这只票，按「数据准备」补数，或把数据源改成 AKShare 让它在线下载。

**补数时报在线源失败**
AKShare 是公网接口，偶发限流或接口变动。隔几分钟重试、缩小日期区间，或切 mootdx。

**AI 复盘报 401 / 连接失败**
设置里点「测试连接」确认 base_url 与模型名；Key 过期或余额不足时接口会直接拒绝；`api.openai.com` 在部分网络下不可达，建议用国内可直接访问的服务地址。

**旧报告打开没有逐笔点评了**
这是 V2.3 的有意行为：逐笔 AI 点评下线，历史数据仍保留在库里，不再展示。

**以前用过的用户名不见了**
删除用户会同时删除其训练记录、设置与档案；若只是想换机器，把 `users/` 与 `data/` 整个目录拷过去即可。
